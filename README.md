# RERUN Health — Pharmacy Dashboard

Admin and pharmacy management dashboard for RERUN Health, Zimbabwe's medicine finder platform.

## Tech Stack

- **Vite** + **React 18** + **TypeScript**
- **shadcn/ui** + **Tailwind CSS**
- **React Query** for data fetching
- **React Router** for navigation

## Getting Started

```sh
npm install
npm run dev
```

Create a `.env` file:

```
VITE_API_URL=https://rrerun-health-backend.vercel.app
```

## Deployment

Deployed on Vercel. Push to `main` to auto-deploy.
